Version: v2

Context: Minimax engine (max-depth == 8) with alpha-beta pruning to find best moves for Bot.

Improvements: 
  - Shared game board for each node with undo move to clear last played move. No full reconstruction of board at each node.
  - Incremental evaluation of score at each node. Delta score is added for each subsequent move.
